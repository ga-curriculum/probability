## About
Learn key probability terms, apply set operations and probability rules, and solve problems through analytical methods and simulations.


## Learning Objectives

*You will be able to:*

1. Define experiment, outcome, event, and sample space.
2. Calculate the union and intersection of sets.
3. Apply three probability rules.
4. Solve probability problems using simulations.
